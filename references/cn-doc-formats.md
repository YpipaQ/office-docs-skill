> **依据**：GB/T 9704-2012《党政机关公文格式》、《党政机关公文处理工作条例》（中办发〔2012〕14号）；
> 商业文书部分**没有国标**，是行业惯例，文中标「惯例」。本机实测补注：2026-09-30。
> 落地命令见文末，实现在 `scripts/writers.py` 的 `PROFILES`。

## 2. 公文：GB/T 9704-2012 逐项

**版面**

| 项 | 标准值 | Word 里怎么设 |
| --- | --- | --- |
| 用纸 | A4（210×297 mm） | A4 |
| 天头（上白边） | 37 mm ±1 | 上 3.7 cm |
| 订口（左白边） | 28 mm ±1 | 左 2.8 cm |
| 下白边 | 35 mm ±1 | 下 3.5 cm |
| 右白边 | 26 mm ±1 | 右 2.6 cm |
| 版心 | 156 × 225 mm | —（由上面五项决定） |
| 每面行数×每行字数 | 22 行 × 28 字 | 行距**固定值 ≈29 磅**（225 mm=637.8 pt÷22） |

**字体字号（逐要素）**

| 要素 | 字体 | 字号 |
| --- | --- | --- |
| 份号 | — | 3 号阿拉伯数字，6 位，顶格版心左上角第一行 |
| 密级和保密期限 / 紧急程度 | 黑体 | 3 号 |
| 发文机关标志（红头） | 小标宋体，**红色** | 由发文机关自定，上边缘距版心上边缘 35 mm |
| 发文字号 | 仿宋 | 3 号 |
| 签发人姓名 | 楷体 | 3 号（"签发人"三字仍仿宋） |
| 标题 | 小标宋 | **2 号**，居中；回行要词意完整、呈梯形或菱形 |
| 主送机关 | 仿宋 | 3 号，顶格，末尾全角冒号 |
| 正文 | 仿宋 | **3 号**，每段左空二字 |
| 一级层次「一、」 | **黑体** | 3 号 |
| 二级层次「（一）」 | **楷体** | 3 号 |
| 三级「1.」／四级「（1）」 | 仿宋 | 3 号 |
| 附件说明（"附件："） | 仿宋 | 3 号，正文下空一行、左空二字 |
| 发文机关署名、成文日期 | 仿宋 | 3 号 |
| 附注 | 仿宋 | 3 号，左空二字加圆括号，位于成文日期下一行 |
| 页码 | **宋体半角** | **4 号**，形式 `— 1 —`（数字左右各一条一字线），奇页右空一字、偶页左空一字，一字线上距版心下边缘 7 mm |
| 版记（抄送、印发机关/日期） | 仿宋 | 4 号 |

**规则细节（对稿最常被挑的）**

- 层次序数依次为 `一、` `（一）` `1.` `（1）`；**"一、"后面不加顿号以外的点号**，标准写法就是"一、xxx"。
- 成文日期：**阿拉伯数字标全**，年份写全称（2026 年，不写 26 年），月、日**不编虚位**（1 月不写 01 月）。
- 发文字号用**六角括号〔〕**，顺序号**不加"第"**、**不编虚位**（1 号不写 01 号）。
- 加盖印章时成文日期**右空四字**；印章红色、不得出现空白印章，端正居中下压署名和日期。
- 版记分隔线：与版心等宽，**首末条粗线（0.35 mm）**、中间细线（0.25 mm）。
- 附件："附件"二字及顺序号用**3 号黑体**顶格；附件另面编排，标题居中于版心第三行。
- 装订：左侧装订，骑马订/平订的订位在距版面上下边缘各 70 mm 处，平订钉锯距书脊 3–5 mm。
- 公文首页**必须显示正文**；一页只剩落款放不下时，用调行距/字距解决，不许空转页。

## 3. 本机字体现实（关键取舍）

公文要求的 `仿宋_GB2312`、`楷体_GB2312`、`方正小标宋简体` 在 Linux 上不是原生字体。
本技能的策略是**两层**：

**第一层（2026-09-30 起已装）**：装免费中文字库 + 一层 fontconfig 别名，让**标准字体名直接用**，
docx 里照写「仿宋_GB2312」「宋体」即可，本机与 Windows 两端都对：

```bash
sudo bash scripts/install_fonts.sh        # 幂等；--check 只体检
```

| 标准字体名 | 本机实际落到 | 类型是否对 |
| --- | --- | --- |
| 宋体 / SimSun / 方正小标宋简体 | 文鼎PL简报宋（AR PL SungtiL GB） | ✅ 衬线宋体 |
| 仿宋_GB2312 / 仿宋 / FangSong | cwTeX 仿宋體 | ✅ 仿宋 |
| 楷体_GB2312 / 楷体 / KaiTi | 霞鹜文楷（LXGW WenKai） | ✅ 楷体 |
| 黑体 / SimHei / 微软雅黑 / 等线 | Noto Sans CJK SC | ✅ 无衬线黑体 |

**为什么必须显式配这层**：不配时 `fc-match 宋体` 会落到 **Noto Sans CJK（无衬线）**，
宋体渲染成黑体；而 docx 里存的字名仍是「宋体」，**在 Windows 上打开是对的、本机出 PDF 是错的**，
光看文件根本发现不了。`doctor` 的 `font_aliases_bad` 就是查这个。

**第二层（`--portable`，现已很少需要）**：把生成的 docx 字体名直接换成 Noto CJK。
只用于**没有别名层的旧环境**兜底；本机正常不要加，加了反而把仿宋/楷体降级成 Noto 衬线。

⇒ 即便两层都在，本机字形仍是**替身**：字宽与微软/方正原字体有差，**每行字数与分页会漂**。
要交付"逐字对齐版心"的正式公文，仍须用装了原字体的 Windows/WPS 出终稿；本机适合起草、校对内容与结构。

## 4. 商业文书（惯例，无国标）

| 文书 | 页面 | 标题 | 正文 | 行距 | 其他惯例 |
| --- | --- | --- | --- | --- | --- |
| **合同/协议** | A4，上下 2.54 cm、左右 3.17 cm（或四周 2.5 cm） | 2 号黑体居中；"合同编号"右对齐五号 | 小四宋体 | 1.5 倍 | 条款题"第一条"小四黑体；甲乙方信息表格式；末页双方名称＋盖章位＋日期；骑缝/逐页小签 |
| **商务函件** | A4，四周 2.54 cm | 小二黑体居中 | 小四宋体 | 1.5 倍 | 称呼顶格加全角冒号；"此致/敬礼"或"特此函告"；落款右对齐；日期写全 |
| **报告/方案** | A4，上下 2.54 cm、左右 2.8–3.17 cm | 封面用一号/小二黑体；内页标题小二 | 小四宋体 | 1.5 倍 | 一级标题小三黑体、二级四号黑体；图表题注五号居中、"图 1/表 1"编号；目录页码与正文一致 |
| **投标文件** | 严格照招标文件的"投标文件格式"章 | 按格式表 | 一般小四宋体 | 1.5 倍 | 正/副本份数、密封与骑缝章、逐页签字、资格文件按目录顺序、偏离表不得漏项 |
| **汇报 PPT** | 16:9 | 28–32 pt 微软雅黑加粗 | 18–20 pt | 单倍(1.2) | 每页 ≤6 行、每行 ≤20 字；页脚页码；图表题注 12 pt；避免整段文字 |
| **报价单/台账表** | A4 横向或纵向 | 五号/小四加粗居中 | 五号或小四宋体 | 单倍 | 表头加粗居中、数字右对齐、金额两位小数、合计行加粗；跨页重复表头 |

**通用惯例**：正文中文用宋体/仿宋、西文数字用 Times New Roman；中文标点全角；数字用半角阿拉伯数字；
"二〇二六年"式中文数字只用于极正式场合（公文成文日期已改为阿拉伯数字）。

## 5. 高频错误对稿清单

1. 年份简写（"26 年"）、月日编虚位（"09 月"）。
2. 发文字号用了方头括号【】而不是六角括号〔〕，或写了"第 1 号"。
3. 层次序号乱序（跳级用 `（一）` 或混用 `1、` 与 `1.`）。
4. 标题回行把词组切断、居中不居中、字号不是 2 号小标宋。
5. 正文没左空二字（首行缩进 2 字符），或全文用两端对齐导致字距忽大忽小（公文一般两端对齐但字距要匀）。
6. 页码没有一字线、奇偶页位置相同、用了 5 号字。
7. 附件说明写成"附：xxx"或"附件 1:xxx"（标准是"附件：1. xxx"，名称后不加标点）。
8. 用阿拉伯数字当层次第一层（`1.` 当一级），或中文数字与阿拉伯数字混排无规律。
9. 行距设成固定值却没算版心（22 行/面被挤成 20 行或 24 行）。
10. 直接改了正文却没同步附件/版记里的机关名称与日期。

## 6. 本技能怎么用

```bash
# 标准公文（版心 3.7/3.5/2.8/2.6 cm、三号仿宋、29 磅固定行距、层次字体自动）
python3 scripts/office_cli.py docx-new --spec gongwen.json -o 通知.docx --profile gongwen

# 合同 / 报告
python3 scripts/office_cli.py docx-new --spec contract.json -o 合同.docx --profile contract
python3 scripts/office_cli.py docx-new --spec report.json   -o 方案.docx --profile report

# 汇报 PPT
python3 scripts/office_cli.py pptx-new --spec brief.json -o 汇报.pptx --profile brief

# 出图核对（本机字形是替身，字宽有差 —— 用于看版式，不作逐字对齐的最终交付）
python3 scripts/office_cli.py thumb 通知.docx -o thumbs/
```

**默认不要加 `--portable`**：本机已装字库 + fontconfig 别名（见第 3 节），国标字体名直接就能正确渲染
（仿宋→cwTeX 仿宋、楷体→霞鹜文楷、宋体→文鼎宋），而且 docx 拿到 Windows/WPS 上也是对的。
`--portable` 只留给**没有别名层的旧环境**兜底。
